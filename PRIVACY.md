# Privacy Policy & Local Guarantee

**WeddingCull v1.0.0** is designed from the ground up for strict privacy:

1. **100% Local Processing**: All photo scanning, metadata extraction, preview generation, quality scoring, face detection, clustering, and export occur exclusively on your local Mac.
2. **Zero Telemetry**: WeddingCull does not collect, transmit, or log any user data, usage statistics, crash analytics, or metadata.
3. **No Cloud Upload**: No photograph or facial embedding is ever uploaded to any cloud server or third-party service.
4. **No Runtime Network Access**: WeddingCull operates completely disconnected from the Internet.
5. **Original File Integrity**: Your original files are never altered, rotated, renamed, or modified.
